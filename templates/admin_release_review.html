Section 1 • Engineering Summary

Verified Engineering Deliverables (v{{ app_version | default('0.5.2') }})

5 Core Capabilities

Workstream A: Streamable HTTP JSON-RPC 2.0 MCP Gateway (services/mcp_service.py, routes/mcp.py, vendor/hvl_common/mcp/)

Problem: External AI assistants (Gemini Ultra, Antigravity, Gemini CLI, Claude Desktop, Cursor) could not query household financial state or run ephemeral simulations directly without consuming server-side Gemini API quota.
Fix: Built a permissioned Model Context Protocol (StreamableHTTP JSON-RPC 2.0) server mounted at POST /mcp with multi-worker file-backed rate limiting (60/min valid RPCs, 10/min brute-force auth failures with HTTP 429 + Retry-After), exposing 20 non-mutating tools (16 read + 4 simulate).

Workstream B: Zero-Knowledge Token-Wrapped Vault Encryption & Two-Layer Mutation Firewall (vendor/hvl_common/mcp/tokens.py)

Problem: When Allow Support Access is OFF (support_access_enabled = 0), the server stores encryption_key_enc = NULL, so stateless Bearer-token MCP calls have no browser cookie (__Host-hvl_vault_fek) to decrypt the household vault.
Fix: At token-mint time (while the authenticated browser session holds vault_fek), the household encryption key is wrapped via Fernet(SHA256(raw_token + server_secret)) and stored in mcp_tokens.wrapped_secret. Only a caller presenting the raw hvl_mcp_... bearer token can unwrap vault_fek in memory for the duration of the request. Mutating tools (manage_scenario_life_event, manage_lp_commitment, update_tax_document_checklist_status) are excluded from the MCP registry and blocked by a second tier check in server.py.

Workstream C: 22-Tool AI Advisor — Chief of Staff Radar, Annual Cash Flow Waterfall & Ephemeral Life Events (tools_chief_of_staff.py, tools_tabs.py)

Problem: Daily executive briefings required 5+ separate tool calls across tabs, year-by-year cash-flow waterfalls could not be queried for a single target year/age, and testing a life event over MCP required a non-persisted simulation tool.
Fix: Expanded the AI Advisor from 19 to 22 deterministic tools: (1) get_chief_of_staff_radar aggregates sync freshness, Household Readiness Audit action items, pending Tax Season forms, quarterly Safe Harbor pacing, LP unfunded capital calls/stale marks, and DAF/gift exclusion headroom in one call; (2) get_annual_cash_flow_detail drills into any projection year or age; and (3) simulate_life_event_impact clones the active plan in memory (persisted_to_db: False) and returns Before vs. After net worth deltas at ages 65/85/95 and Monte Carlo solvency impact.

Workstream D: Settings MCP Assistant Card & Mobile 375px Viewport Hardening (_mcp_assistant.html, accounts.html, estate.html)

Problem: Households needed self-service UI controls to mint, rotate, pause, or revoke per-member MCP keys, and 3 long action buttons/toolbars overflowed on 375px mobile viewports.
Fix: Added the Personal Assistant (MCP Gateway) section in templates/components/settings/_mcp_assistant.html aligned with HVL design tokens, and added responsive wrapping to the Monarch core burn bar (accounts.html), Sankey year scrubber (cash_flow_sankey.js), and Estate audit verification buttons (estate.html).
