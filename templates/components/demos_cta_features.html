Operating Modes & Sample Households

Cloud Vault, Anonymous Workspace, or Standalone Local App

1. Cloud Vault Google Sign-In • Saved Across Sessions

Hosted Encrypted Vault

Sign in with Google to save your encrypted household database across sessions and devices, with optional spouse/partner access. Your decryption key is stored in your personal Google Drive (appDataFolder).

Retention note: Hosted as a free, non-commercial hobby project with no uptime/retention SLA (vaults inactive >365 days may be deleted). Export a .fovault backup anytime.

Cloud Vault Sign In →
2. Anonymous Workspace No Login • 24h/7d Auto-Wipe

Zero-Retention Web Workspace

Use all planning tools immediately with no account or login. Encrypted with a browser-only key and automatically wiped from the server after 24 hours (extendable to 7 days).

Local file persistence: Download an encrypted .fovault file to your computer anytime and re-open it in any future session (survives clearing browser cache).

3. Standalone Local App macOS • Windows • Docker

100% Offline Desktop & Self-Hosted

Run entirely on your own hardware on 127.0.0.1:5050 via native macOS/Windows installers or Docker, unlocked with a local PIN or passphrase.

Permanent local storage: Your encrypted SQLite database lives permanently in your OS user data folder with zero external server dependency.
